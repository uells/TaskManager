# TasksManager - Инструкции для Claude Code

## 📚 Цель проекта
Учебный pet-проект для изучения современного стека:
- **FastAPI** - асинхронный фреймворк
- **SQLAlchemy** (async ORM) - работа с БД
- **Pydantic** - валидация данных
- **AppSec принципы** - безопасность приложений

## 🎯 Подход к разработке

**⚠️ ВАЖНО: Пользователь учится - НЕ пишите полный код!**

- Объясняйте концепции и паттерны
- Давайте подсказки и наводящие вопросы
- Помогайте разбираться в ошибках
- Указывайте на документацию
- Позволяйте пользователю писать код, затем рецензируйте его
- Задавайте вопросы перед реализацией: "Что вы думаете, как это сделать?"

## 📋 Текущие приоритеты

### Фаза 1: AppSec основы (ТЕКУЩАЯ)
1. JWT аутентификация (login endpoint)
2. Авторизация (проверка прав доступа)
3. Логирование действий пользователей
4. Убрать debug информацию (database.py:8)
5. Добавить requirements.txt

### Фаза 2: Backend функциональность
- Полный CRUD для всех сущностей
- Фильтрация, поиск, пагинация
- Получить задачи по сотруднику/месяцу
- Alembic миграции

### Фаза 3: AI + Экспорт
- Claude API интеграция для переформулировки задач
- Экспорт в .doc
- Тесты

## 🔒 AppSec замечания
- User регистрация готова ✅
- Пароли хешируются правильно (pwdlib) ✅
- **НО:** Нет аутентификации - это критично!
- Любой может создавать/менять задачи без логина
- Нужна валидация входных данных (SQL injection, XSS)

## 📁 Структура проекта
```
backend/app/
├── main.py          # FastAPI app + router
├── database.py      # SQLAlchemy setup
├── models.py        # ORM модели (User, Task, Category)
├── schemas.py       # Pydantic валидация
├── repositories.py  # Data access layer
└── security.py      # Хеширование паролей
```

## 🛠️ Полезные команды
- `docker-compose up` - запустить PostgreSQL
- `.env-template` - шаблон переменных окружения
